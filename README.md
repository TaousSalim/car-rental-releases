# Kira, car rental manager

Kira helps small car rental agencies manage their fleet, rentals, availability, maintenance and clients. Everything stays on the agency's own computer. A license key is required after the 30 day free trial.

## Download (version 1.0.2)

| Computer | Download |
|---|---|
| Windows 10 or 11 | [Kira-Setup-Windows.exe](https://github.com/TaousSalim/car-rental-releases/releases/latest/download/Kira-Setup-Windows.exe) |
| Mac (Apple Silicon and Intel) | [Kira-macOS.dmg](https://github.com/TaousSalim/car-rental-releases/releases/latest/download/Kira-macOS.dmg) |

Kira updates itself: when a new version is out, a small card appears in the app. One click installs it (your data is backed up first).

### First install on Windows

Windows may show "Windows protected your PC" because the installer is not code signed yet. Click **More info**, then **Run anyway**. No administrator password is needed.

### First install on Mac

Open the dmg and drag Kira to Applications. The first time, open the Applications folder, **right click Kira and choose Open**, then click **Open** again. If macOS still refuses, go to System Settings, Privacy and Security, and click **Open Anyway** next to the Kira message.
